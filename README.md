# Omar Ismail — Portfolio

Dark-mode engineering portfolio cloned from [moustafasharaf.com](https://moustafasharaf.com/), built with React 19, Tailwind CSS 4, and Vite.

**New here?** See **[docs/getting-started.md](docs/getting-started.md)** for install, dev server, and first edits.

## Stack

- React 19 + TypeScript
- Tailwind CSS 4 (`@tailwindcss/vite`)
- Bun

## Commands

| Command | Description |
|---------|-------------|
| `bun install` | Install dependencies |
| `bun run dev` | Dev server (port 8080) |
| `bun run build` | Production build |
| `bun run preview` | Preview production build |

## Edit your content

All copy, projects, stats, and links live in **`src/content/site.json`**.

See **[src/content/README.md](src/content/README.md)** for a field-by-field guide. Replace images in `public/images/` and update paths in JSON.

## Design

- Dark-only green + purple palette
- Fonts: Instrument Serif, DM Sans, DM Mono (Google Fonts)
